## The word

> murmuration

The first word that came to mind: a murmuration — thousands of
starlings wheeling as one dark ribbon across the evening sky. One word,
but it carries a whole scene: surprise (a word most people rarely say),
vividness (you can see the flock turn), and a spark of wit (a crowd
that moves like a single mind, with no leader at all).

## Run it

```sh
node main.ts
```

This writes the word to `/output/entry.txt` (12 bytes: `murmuration` + newline),
valid UTF-8, well inside the 1–24 character gate — and prints it to stdout.
